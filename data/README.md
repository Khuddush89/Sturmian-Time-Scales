# 🔢 Reference data

These 20 CSV files are regenerated by verification followed by figure generation.
Files named `figure*.csv` contain plotting data; the remaining files record
exact examples, spectra, refinement, thresholds, and zero counts.

```bash
sturmian verify --output outputs/reference
sturmian figures --output outputs/reference
```

Floating-point residuals may vary in their last digits. Exact Fraction values
and high-precision Decimal strings are preserved as text in their CSV columns.
See [reproducibility](../docs/reproducibility.md) before comparing datasets.
