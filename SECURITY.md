# 🔐 Security policy

## Supported versions

Security fixes are provided for the latest `0.1.x` release and the `main` branch.
Older versions should be updated before submitting a report.

## Report a vulnerability

Use the repository's private vulnerability reporting feature when enabled,
or email **khuddush89@gmail.com** with the affected commit, environment,
reproduction steps, and expected impact.

Please keep exploit details private until a fix or coordinated disclosure is ready.
Maintainers will review the report and coordinate next steps without promising
a response deadline that the project cannot guarantee.

## Numerical correctness

Incorrect spectra, counting conventions, or tolerances should normally be filed
as bug reports with a minimal example. Report them privately when they also
expose a security vulnerability or sensitive information.
